# Bitfloraのコンセプト

## 概要

Bitfloraは、バイトの世界に生まれた小さなデジタル生命体を育てるシミュレーションです。

プレイヤーはBitfloraの状態を見ながら行動を選びます。行動と時間経過によって経験値や各種状態が変化し、その積み重ねが成長や進化につながります。

既存作品のキャラクターや固有設定は使用せず、Bitflora独自の世界と仕組みを作ります。

## このリポジトリの目的

主目的はRustの学習です。題材として育成ゲームを使い、必要になった機能からRustの仕組みを学びます。

特に次の要素を扱います。

- 関数、型、構造体
- `enum`による状態や行動の表現
- 所有権と借用
- モジュール分割
- `Result`を使ったエラー処理
- ユニットテスト
- 状態の保存と復元

ゲームの規模を大きくすることよりも、追加したルールを型とテストで説明できる状態を優先します。

## 基本となる遊び

基本ループは次の4段階です。

1. Bitfloraの現在状態を確認する
2. 育成、休息などの行動を選ぶ
3. 行動の結果と時間経過を反映する
4. 成長条件を判定する

最初からすべてを実装するのではなく、このループを成立させる最小単位から追加します。

## 最初の到達点

最初のバージョンでは、ターミナル上で1体のBitfloraを育てられる状態を目指します。

対象にする機能は次のとおりです。

- 1体のBitfloraを作成する
- 名前、経験値、レベルを表示する
- 育成行動によって経験値を得る
- 経験値に応じてレベルを計算する
- 一連の操作を繰り返せるようにする
- 成長ルールをユニットテストで確認する

## 現段階で対象にしないもの

最初の到達点には、次の機能を含めません。

- GUI
- オンライン通信
- マルチプレイ
- 課金
- 複雑な戦闘
- 多数の生物や進化系統
- 外部データベース

これらは、基本ループが動いた後に必要性を判断します。

## 将来の拡張候補

以下は方向性の候補であり、実装を確約する仕様ではありません。

- 食事、体力、機嫌などの状態
- 行動履歴によって変わる成長
- 複数の進化先
- 対戦または探索
- セーブとロード
- TUIまたはGUI
- WebAssemblyによるブラウザ対応

## 開発方針

- 小さな関数とテストから追加する
- ルールを先に明文化してから実装する
- 状態を文字列ではなく型で表現する
- 不要な依存ライブラリを増やさない
- 学習段階を飛ばす大規模な実装を一度に追加しない
